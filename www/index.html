How to Play

Phone

  • Left stick: walk (push all the way to run)
  • Drag right side: look around
  • Tap screen / ■ button: place block
  • Hold screen / ⛏ button: break block
  • ▲: jump / swim / fly up
  • FLY: toggle flying
  • ⋯: choose blocks
  • Tap a door to open/close it
  • Tap a bed at night to sleep

Computer

  • WASD: walk · Ctrl: run
  • Mouse: look · Space: jump
  • Left click: break · Right click: place
  • Middle click: pick block
  • 1-9 / wheel: select · E: blocks
  • F or double Space: fly · Shift: fly down
  • Right click a door: open/close · a bed: sleep
  • Esc: pause · F3: debug info
